# Task Manager

A simple to-do app built with HTML, CSS, and vanilla JavaScript.

**Live demo:** _add your GitHub Pages link here_

## Features

- Add, edit, and delete tasks
- Mark tasks as done
- Filter by All, Active, or Done
- Task counter and "Clear completed"
- Tasks are saved in the browser (localStorage), so they stay after a refresh
- Works on phones and desktops, and can be used with a keyboard

## Files

- `index.html`: the page structure
- `style.css`: the styling
- `script.js`: the app logic

## What I learned

- Handling events and updating the page with the DOM
- Keeping app data in one place (an array of tasks) and redrawing the list from it
- Saving data with localStorage and handling cases where it fails
- Building a layout that works on small screens

## Run locally

Open `index.html` in a browser.
